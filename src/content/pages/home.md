## A decentralized blockchain project

Inspired by the iconic Pepe meme, this platform has been created on f**irst layer blockchain**, fostering creativity and global collaboration. The mission is to bridge the gap between people of all languages and skillsets, connecting them through a decentralized network that supports learning, growth, and real-world opportunities.

The PepePow whitepaper outlines a new blockchain project built around the popular Pepe meme. PepePow aims to provide a platform for community collaboration, skill development, and forming global connections. The network is secured through proof-of-work mining and incentivized by both miners and masternodes.

### PEPEPOW's Survival

PEPEPOW encountered a chain disconnection and subsequent death incident. Following this survival, the developer fee was suspended for an extended period.

### Developer Fee Reinstated

Following the vote, the developer fee was reinstated, and the development process is progressing forward.

### 1. API Server

Completed

**Core purpose:** REST backend for wallets, explorers, and external apps. Backbone for fast sync, balance, and transaction queries.

Difficulty: Medium

### 2. ElectrumX Server

Completed

**Core purpose:** Lightweight backend for SPV/light wallets, enabling fast address balance and transaction history queries without full node sync.

Difficulty: Medium-High

### 3. Web Wallet (Non-custodial)

Completed

**Core purpose:** Browser-based wallet for key generation, balance viewing, and sending transactions without a custodian.

Difficulty: Medium

### 4. PepewPay – Payment Link / POS PWA

Not Completed

**Core purpose:** One-page merchant payment system with payment links, QR codes, and live confirmation for in-store and online payments.

Difficulty: Medium

### 5. JS/TS SDK (pepew-js)

Not Completed

**Core purpose:** Unified JavaScript/TypeScript toolkit for key derivation, transaction building/signing, and REST/WebSocket integration.

Difficulty: Medium

### 6. Mobile Wallet (Android / iOS)

Partially Completed

**Core purpose:** Native mobile wallet with fast sync, PIN/biometric lock, QR scanning, and push notifications.

Difficulty: Medium-High

### 7. Telegram Mini Wallet Bot

Completed

**Core purpose:** Social wallet inside Telegram for tipping, micro-payments, and easy onboarding.

Difficulty: Medium-High

### 8. PEPEW Inscriptions & Viewer

Not Completed

**Core purpose:** On-chain creative ecosystem (Ordinals-style) with explorer viewer for inscriptions.

Difficulty: Medium

### 9. Unity Game Kit v1

Not Completed

**Core purpose:** Demo for integrating PEPEPOW into Unity games so players can earn and spend PEPEW.

Difficulty: Medium

### 10. Masternode / Staking Tools & Monitoring

Partially Completed

**Core purpose:** Tools and dashboards for automatic masternode setup, reward tracking, and status alerts.

Difficulty: Medium-High

### 11. Multi-signature Vault Wallet

Not Completed

**Core purpose:** Secure multi-signature treasury for teams or DAOs with approval workflows and optional time-locks.

Difficulty: Medium-High

### 12. Minimal Oracle Gateway

Not Completed

**Core purpose:** Provide signed and verifiable price and event feeds for bridges and on-chain applications.

Difficulty: High

### 13. Liquidity Pool (wPEPEW on EVM or other chains)

Not Completed

**Core purpose:** Deploy wrapped PEPEW and create a USDT/wPEPEW liquidity pool for trading and price discovery.

Difficulty: High

### 14. DEX Aggregator Integration

Not Completed

**Core purpose:** Integrate wPEPEW into major DEX aggregators (e.g., 1inch, Matcha) to expand liquidity and visibility.

Difficulty: High

Completed

**Core purpose:** Maintain HooHash-compatible mining tools, pool software, Stratum services, monitoring, reward accounting, and operator documentation.
