In CMD window:
- `PEPEPOW-cli mnsync status`: Shows masternode status during startup.
- `PEPEPOW-cli masternode status`: Indicates if you need to run start-all.
- `PEPEPOW-cli getbalance`: Displays wallet balance.
- `PEPEPOW-cli masternodelist info 87.124`: Provides information on masternodes with the IP address 87.124 (Change IP to filter another address).
- `PEPEPOW-cli stop`: Stops the masternode and exits the process.
