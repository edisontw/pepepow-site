The legacy PEPEPOW web wallet will be retired and shut down soon.
This service had already been planned for retirement. A newer web wallet option has been available for approximately four months, and the community now has a better alternative for users who prefer a web-based wallet.
Recently, the legacy web wallet showed signs of possible unauthorized access or abnormal balance movement. The exact cause remains unclear. Because the legacy wallet has been running for a long time with limited maintenance, the safest path is to help users withdraw remaining funds and then fully retire the service.

## What Users Should Do

Users who still have PEPEW in the legacy web wallet should withdraw their funds as soon as possible.
Please do not deposit any new funds into the legacy web wallet.
Users are encouraged to move to the newer web wallet option or use the PEPEPOW desktop wallet.
After the withdrawal period, the legacy web wallet service will be shut down.

## Community Support

Community members have helped top up the legacy wallet to support pending withdrawals. This was done to help users move their remaining funds out as safely as possible before the service is retired.
This decision is part of PEPEPOW’s ongoing effort to improve security, reduce legacy risk, and keep the ecosystem moving toward more reliable tools.
Thank you to everyone who continues to support PEPEPOW and help protect the community.
