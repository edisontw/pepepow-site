## PEPEW Light Wallet is now available

Following the launch of the PEPEW Light service, the PEPEW Light Wallet is now available.
**PEPEW Light Wallet:**
<https://light.pepepow.net/wallet/>
PEPEW Light Web Wallet is now the recommended wallet entry for PEPEPOW users.
The previous web wallet remains available as a backup:
<https://wallet.pepepow.net>
The PEPEW Light Wallet provides lightweight wallet access for PEPEPOW users.
It is similar in purpose to the previous web wallet, but the backend is now powered by the ElectrumX-based pepepow-electrumx-service through PEPEW Light.
This gives the wallet a cleaner and more expandable foundation for future development.

### Key features

- Lightweight PEPEW wallet access
- Refresh UTXOs and Consolidate feature
- ElectrumX-based backend service
- Better foundation for future wallet tools
- Non-custodial direction: users remain responsible for their own keys and wallet safety

The PEPEW Light Wallet is part of a larger infrastructure direction.
With PEPEW Light as the service layer, future development can continue toward mobile wallets, payment tools, Telegram wallet functions, developer SDKs, and other community applications.
As always, please use wallets carefully, back up your private keys, and avoid keeping large balances in any new or beta wallet service.
PEPEPOW keeps building.
