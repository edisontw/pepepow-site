**Happy New Year 2026!**
Wishing everyone a great year ahead.
After extensive development, testing, and refinement,
the PEPEPOW Android Wallet is now completed and officially released.
This marks an important milestone for the PEPEPOW ecosystem, enabling users to create and use a fully non-custodial PEPEPOW wallet directly on mobile, with fast and practical usability.
Download & Release Notes (GitHub)
<https://github.com/edisontw/pepepow-android-wallet/releases>
**Important Notes (Please Read Carefully)**
To avoid confusion or potential asset issues, please read the following carefully.
**1. New wallet creation only**
This version does NOT support importing existing wallets
Mnemonic recovery / restore is NOT supported
**2. Back up your mnemonic securely**
The mnemonic generated on mobile must be saved immediately
You may restore this mnemonic on the desktop wallet
Warning: Once the same mnemonic is used on desktop, do NOT continue using it on mobile, as this may cause balance inconsistencies
**3. Default fast sync mode (FAST boot)**
Designed for fast usability, typically usable within ~20–30 seconds
FULL SPV mode is only partially implemented, slow and still buggy, and not recommended
**4. Security model**
Fully non-custodial
Private keys / mnemonics remain on your device only
API-based fast sync improves usability but never controls or holds user funds
This release is a stable and usable starting point.
Further improvements to SPV, sync logic, and user experience are planned.
Feedback, testing, and contributions are very welcome.
Thank you to everyone supporting and building PEPEPOW together.
