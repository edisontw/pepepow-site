The PEPEPOW community website has completed its migration away from the previous WordPress-based platform.

The new website is now available at:

https://pepepow.net/

The previous PEPEPOW website address has been retained and now redirects visitors to the new website.

The migration provides a cleaner foundation for future updates while making the website easier to maintain alongside other PEPEPOW community infrastructure.

In keeping with PEPEPOW's open-development approach, the website source code is publicly available on GitHub:

[https://github.com/edisontw/pepepow-site/](https://github.com/edisontw/pepepow-site/)

Community members are welcome to review the code, report issues, suggest improvements, or contribute directly.

**PEPEPOW continues to evolve through decentralized participation, open collaboration, and contributions from its community.**
