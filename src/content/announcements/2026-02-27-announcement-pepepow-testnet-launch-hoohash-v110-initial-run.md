### PEPEPOW Testnet Launch: Hoohash V110 Initial Run

The PEPEPOW testnet is now ready for its first public run using the **Hoohash V110** algorithm. Community participation is encouraged to validate stability and performance before mainnet activation.

#### Beta Core Releases

Linux builds are available: https://pepepow.foztor.net/beta/

- AARCH64
- x86\_64

To participate, run PEPEPOWd and PEPEPOW-cli with the `-testnet` flag.

*(Windows version will be released later.)*

#### Miner Release (v1.4.1 — Feb 25, 2026)

The latest HTN miners support **PEPEPOW\_HOOHASHV110** and require the `--pepepow` parameter.

Downloads:  
<https://htn.foztor.net/>

Testnet stratum:

stratum+tcp://stratum-eu.pepepow.foztor.net:3095

- Hoohash specification
- Multi-hashing reference implementation

RPC specifications remain unchanged.

#### Important Notes

Mainnet activation will be protected by SPORK. ARM64 CPU and AMD GPU miners are still under development.

The tentative timeline for mainnet activation is approximately **four weeks**, depending on successful testnet validation.

Community testing is essential to ensure a smooth and reliable launch.
