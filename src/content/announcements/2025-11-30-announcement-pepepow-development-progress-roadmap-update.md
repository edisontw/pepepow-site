## **PEPEPOW Development Progress & Roadmap Update**

Hey everyone! Here’s an update on what has been completed so far and what’s coming next for the PEPEPOW ecosystem. A huge thank you to all contributors and community members pushing the project forward!

### **Completed Development (Current Status)**

- Website – Foztor, Edison, TrooperD
- Core Wallet (PePe-core) – Foztor
- Blockchain Explorer – Foztor, Edison
- Mining Pool – Foztor
- Miner (CPU/GPU) – Foztor
- Web Wallet – Beta – Foztor
- Dice Playground – Foztor
- API Server – *near completion*
- Mobile Wallet v1 – *near completion*

More details:<https://pepepow.org>

### **Next Phase Development Focus**

#### **Wallets & User Experience**

- Full non-custodial Web Wallet
- Mobile Wallet v1 public release
- Telegram Mini Wallet Bot
- PepewPay (one-page payment links / POS)

#### **Developer Tools**

- JS/TS SDK (pepew-js)
- ElectrumX Server
- API expansion for wallet sync, masternode data, inscriptions, and more

#### **On-chain Features**

- PEPEW Inscriptions (Ordinals-style) + Viewer
- Masternode / Staking Tools & Dashboard
- Multi-Signature Vault Wallet

#### **DeFi & Ecosystem Growth**

- Minimal Oracle Gateway
- Liquidity Pool (wPEPEW on EVM or other chain)
- DEX Aggregator Integration

### **Community Involvement**

We always welcome contributors—developers, designers, researchers, content creators, testers, and anyone who wants to help! If you’re interested in participating, feel free to join discussions and share your ideas.

Even small contributions move the project forward.  
**Let’s keep building PEPEPOW together!**
