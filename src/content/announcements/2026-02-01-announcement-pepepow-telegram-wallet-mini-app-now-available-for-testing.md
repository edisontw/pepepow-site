We are pleased to announce that the **PEPEPOW Telegram Wallet (Mini App)** is now open for public testing.
Telegram: @pepepow\_walletbot
This wallet is built on the same non-custodial architecture as the PEPEPOW Web Wallet. *Private keys and mnemonic phrases are generated and stored exclusively on the user’s device, and all transactions are signed locall*y.
In addition to standard wallet functions, the Telegram Mini App allows users to transfer PEPEW directly to other Telegram users.
The backend service stores only minimal data required for operation, including the Telegram user ID and the default PEPEPOW address. It does not store private keys, mnemonic phrases, or signed transactions.
A detailed user guide is available at:
<https://github.com/edisontw/pepepow-wallet-suite/blob/main/docs/telegram-user-guide.md>
Feedback, bug reports, and developer contributions are welcome during the testing phase.
