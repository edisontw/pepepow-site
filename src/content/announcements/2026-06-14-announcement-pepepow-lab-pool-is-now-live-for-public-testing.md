**PEPEPOW Lab Pool is an open-source**, development-focused mining pool implementation built specifically for PEPEPOW. It is designed to support pool operation, dashboard visibility, API endpoints, monitoring, reward estimation tools, and future transparency improvements.
Initial testing is working normally so far. Stratum mining is working, blocks can be found, the dashboard is online, and API endpoints are available.
The homepage also includes early mining intelligence features, including a **mining reward calculator**, PEPEW / USDT estimate, network hashrate visibility, pool share estimation, and basic reward outlook information. These tools are intended to help miners better understand expected rewards, market-value estimates, and short-term reward variation.
PEPEPOW Lab Pool is not intended to replace existing community infrastructure. Foztor’s pool remains the long-running PEPEPOW community pool. PEPEPOW Lab Pool is positioned as a separate lab-style pool for development, testing, open-source infrastructure, monitoring tools, and reward transparency.
The pool is still being monitored and optimized. Miner feedback is welcome, especially regarding accepted rate, reward estimates, payout behavior, dashboard usability, and overall stability.
*More independent pool infrastructure can help improve PEPEPOW decentralization, resilience, miner choice, and network visibility.*
