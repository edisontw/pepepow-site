**Wallet Improvements • Masternode Reliability • Multiplatform Builds**

PEPEPOW Core v2.9.0.6 brings a collection of wallet usability, performance and stability improvements.

**What's New**

- Improved Qt wallet responsiveness, especially for wallets with large transaction histories.
- Enhanced Coin Control, Send All and UTXO consolidation.
- Improved Masternode status display, management and Recovery validation.
- Better transaction error reporting and safer wallet shutdown.
- Official Windows x64, Linux x64 and Linux ARM64 packages.

**Verification**

All three official GitHub Actions builds passed. SHA256 checksums have been verified, and Windows Qt wallet testing was completed successfully.

**Optional Upgrade**

No consensus or network protocol changes are intended in this release. Existing Masternode reward-selection rules remain unchanged.

Please back up your wallet before updating.
